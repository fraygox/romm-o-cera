# RomM-o-Cera documentation

Start with the [main README](../README.md) to install it. These pages cover
everything it does, one topic each. They're easiest to read on the
[documentation site](https://fraygox.github.io/romm-o-cera/), which has search.

| Page | What's in it |
|---|---|
| [Browsing and downloading](browsing-and-downloading.md) | Finding games, Game night, Backlog, the list menu and its filters, collections, Play now, the download queue, space, download hours, game info |
| [On this box](on-this-box.md) | The On this box menu: games from RomM, space (freeing it, leftovers), compressing games already here, BIOS files, Check games, conversions, game info |
| [Disc compression](disc-compression.md) | CHD, GameCube/Wii RVZ, making Xbox images bootable, Xbox squashfs, 3DS .zcci, Xbox 360 .zar, Wii U .wux and .wua, safety, converting a library you already have |
| [PS3 games](ps3.md) | `.ps3` game folders, encrypted discs and disc keys for games you own: where they go (`bios/ps3keys`), keeping them in RomM, how a key is matched |
| [Wii U games](wiiu.md) | `.wud`, `.wux` and `.wua` explained, the two Wii U switches, disc keys for games you own, updates and DLC |
| [Settings](settings.md) | Every setting, `config.json` (and resetting it), `deploy.sh` and environment variables |
| [Themes](themes.md) | The theme picker, every theme and its OLED version, your own Custom theme, Match theme to controller |
| [Connecting to RomM](connecting.md) | HTTPS, self-signed certificates, plain HTTP, Batocera's network share, auth proxies |
| [Controls](controls.md) | Controller, keyboard, touch and mouse, menus and dialogs, what each button does on every screen |
| [Development](development.md) | Running without a box, the screenshot harness, the docs site, releasing, converter tool builds, tests, the romm and rbui packages, what each file does |

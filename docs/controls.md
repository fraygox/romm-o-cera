# Controls

Button labels follow your controller — Xbox, PlayStation (✕ ○ □ △) or
Nintendo — picked from the controller's name or set in Settings, and switch to
key names while you use a keyboard. Every control on screen (hint bar, menus,
dialogs, messages) is drawn by one helper, so they always match.

**Controller:** south button confirms (switch in Settings) · east back ·
Y search · X list menu · L/R page · L2/R2 previous/next letter · Select
downloads · Start home · **Hotkey + Start exits**. `rommbrowser.pygame.keys`
turns off Batocera's pad-to-keyboard mapping for this app.

**Keyboard:** arrows move · Enter confirm · Esc back · X menu · Y search ·
PgUp/PgDn page · `[` `]` letter jump · Tab downloads · Home home. Search and
text fields take typing directly (Enter runs the search / saves). A keyboard
and a pad work side by side.

**Touch / mouse (basic):** tap a list row to select it, tap again to open; tap
menu entries, keys, buttons and the hint bar; tap the logo for Home and the
breadcrumbs to go back; drag or scroll the wheel to move through lists.

# Mock library credits

The screenshots in the README and on the documentation site come from `tools/mock_romm.py`, a
stand-in RomM server. Its library starts with the real homebrew games below. Each one is published
by its authors under a license that allows redistribution, and that license covers the game and
the images used here. All rights stay with the authors; the licenses are linked below.

What this folder holds for each game (`<slug>/`):

- `cover.png` (or `.jpg`): a portrait cover for the app's cover boxes, **made by us from the game's
  title screen** (scaled with whole-pixel steps and centred on a plain colour taken from its border).
  No box art is used.
- `1.png`, `2.png`, ...: screenshots the project publishes (its repository, its homebrew-database
  entry, or a capture of the released ROM). We scaled them up with whole-pixel steps or down to 640 px wide.
- The short descriptions in `games.json` are our own words.

ROMs are not part of this repository. Sources are the project pages linked below.

Many games came through the community homebrew databases
[gbdev/database](https://github.com/gbdev/database) and
[gbadev-org/games](https://github.com/gbadev-org/games), which mirror the authors' releases;
each license was checked on the project's own page.
